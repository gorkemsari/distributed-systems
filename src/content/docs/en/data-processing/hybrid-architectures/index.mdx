The debate between batch and stream processing often ends with a realization: both are just different ways of viewing the same underlying data. This chapter explores architectures that unify these concepts using the immutable commit log as the ultimate source of truth. We will compare the Lambda and Kappa models, and explore how to turn static, legacy databases into real-time event streams using Change Data Capture.

### Topics Covered

* **[4.3.1. The Commit Log Abstraction: The Core Idea Behind Kafka/Pulsar](/distributed-systems/en/data-processing/hybrid-architectures/commit-log-abstraction/)**: Unpacks the power of the append-only log as the fundamental data structure for distributed streaming and state recovery.
* **[4.3.2. Lambda Architecture: The Complexity of Batch + Speed Layers](/distributed-systems/en/data-processing/hybrid-architectures/lambda-architecture/)**: Examines the traditional approach of maintaining a robust historical batch pipeline alongside a low-latency streaming layer, and the operational overhead it creates.
* **[4.3.3. Kappa Architecture: Everything Is a Stream](/distributed-systems/en/data-processing/hybrid-architectures/kappa-architecture/)**: Explores the modern simplification of treating all data—both historical and real-time—as a single continuous stream.
* **[4.3.4. Log-Structured Merge and Compaction](/distributed-systems/en/data-processing/hybrid-architectures/log-structured-merge/)**: Details how systems keep infinite logs manageable and performant by periodically squashing historical records to retain only the latest state.
* **[4.3.5. Change Data Capture (CDC): Real-Time Synchronization](/distributed-systems/en/data-processing/hybrid-architectures/change-data-capture/)**: Discusses the strategy of eavesdropping on a database's internal transaction log to instantly propagate state changes across the distributed system.
* **[4.3.6. Debezium: Practical Database CDC Implementation](/distributed-systems/en/data-processing/hybrid-architectures/debezium/)**: Looks at the industry-standard tool for connecting traditional relational databases to event-streaming platforms, eliminating the need for fragile dual-write application logic.
