When analyzing massive, bounded datasets where immediate results are not required, batch processing is the foundational approach. This chapter explores the evolution of distributed data processing, from the heavy disk I/O of MapReduce to the in-memory speed of Apache Spark, and how these frameworks guarantee completion despite hardware failures.

### Topics Covered

* **[4.1.1. The MapReduce Paradigm: Functional Roots, Map, Shuffle, Reduce](/distributed-systems/en/data-processing/batch-processing/mapreduce/)**: Breaks down the original paradigm that made distributed data processing accessible, separating computation into independent mappers and aggregators.
* **[4.1.2. Distributed Sort: The Challenge of the Shuffle Phase](/distributed-systems/en/data-processing/batch-processing/distributed-sort/)**: Analyzes the most resource-intensive phase of batch processing, where massive amounts of data must be sorted and moved across the network.
* **[4.1.3. From Hadoop to Apache Spark: Disk vs. In-Memory Processing](/distributed-systems/en/data-processing/batch-processing/hadoop-to-spark/)**: Details the architectural shift from reading/writing to disk at every step to keeping intermediate data in RAM for massive performance gains.
* **[4.1.4. RDD, DataFrame, and Dataset APIs](/distributed-systems/en/data-processing/batch-processing/rdd-dataframe-dataset/)**: Explores the evolution of Spark's APIs, from low-level resilient data structures to highly optimized, SQL-like execution plans.
* **[4.1.5. Checkpointing and Fault Tolerance](/distributed-systems/en/data-processing/batch-processing/checkpointing-fault-tolerance/)**: Covers how batch frameworks guarantee successful job completion even when processing takes hours and physical nodes fail mid-computation.
* **[4.1.6. Straggler Tasks: Speculative Execution](/distributed-systems/en/data-processing/batch-processing/straggler-speculative-execution/)**: Explains how systems prevent a massive distributed job from being bottlenecked by a single slow hardware node by redundantly scheduling tasks.
