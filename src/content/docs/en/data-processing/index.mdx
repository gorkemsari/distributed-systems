Data is only as valuable as our ability to process it and extract actionable insights. This part explores the architectural paradigms used to compute massive datasets at scale, moving from historical, scheduled batch jobs to continuous, real-time stream processing, and how modern systems unify the two.

### Chapters

* **[4.1. Batch Processing](/distributed-systems/en/data-processing/batch-processing/)**: Explores computing over large, bounded datasets, tracing the evolution from the foundational MapReduce paradigm to high-performance, in-memory processing with Apache Spark.
* **[4.2. Stream Processing](/distributed-systems/en/data-processing/stream-processing/)**: Covers continuous, unbounded data processing, the critical distinction between event time and processing time, windowing strategies, and managing late-arriving data with watermarks.
* **[4.3. Hybrid Architectures and the Log Abstraction](/distributed-systems/en/data-processing/hybrid-architectures/)**: Examines how the immutable commit log unifies data flows, comparing Lambda and Kappa architectures, and leveraging Change Data Capture (CDC) for real-time state synchronization.
