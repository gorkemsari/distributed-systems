A service mesh provides a dedicated, transparent infrastructure layer for facilitating service-to-service communications. This chapter, which you can find in **index_58.mdx**, explores the architecture of data planes and control planes, comparing heavyweights like Istio with lightweight alternatives like Linkerd, and detailing how they manage traffic, retries, and telemetry invisibly.



### Topics Covered

* **[10.1.1. Why Service Mesh Exists: L4 vs. L7 Problems](/distributed-systems/en/service-mesh/service-mesh-architecture/why-service-mesh/)**: Explains the limitations of basic IP/TCP routing and the necessity of application-aware (Layer 7) network management.
* **[10.1.2. Envoy Proxy: The Backbone of the Data Plane](/distributed-systems/en/service-mesh/service-mesh-architecture/envoy-proxy/)**: Details the high-performance, edge and service proxy that intercepts and manages traffic for most modern service meshes.
* **[10.1.3. Istio: Control Plane Components (Pilot, Citadel, Galley)](/distributed-systems/en/service-mesh/service-mesh-architecture/istio/)**: Explores the architecture of the most widely adopted service mesh and how its control plane pushes configurations to proxy sidecars.
* **[10.1.4. Linkerd: A Lightweight Alternative with a Rust-Based Proxy](/distributed-systems/en/service-mesh/service-mesh-architecture/linkerd/)**: Compares Istio with an ultra-lightweight mesh optimized for simplicity and minimal resource overhead.
* **[10.1.5. Traffic Management: Load Balancing, Retry, and Fault Injection](/distributed-systems/en/service-mesh/service-mesh-architecture/traffic-management/)**: Covers how to use mesh configurations to implement advanced deployment strategies like canary releases and automated resilience patterns.
* **[10.1.6. Observability at the Mesh Level: Automatic Telemetry](/distributed-systems/en/service-mesh/service-mesh-architecture/mesh-observability/)**: Discusses how a service mesh automatically extracts golden signals (latency, traffic, errors) without modifying application source code.
