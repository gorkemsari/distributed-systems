As the number of microservices in a cluster grows, managing the complex network interactions between them—routing, security, and observability—becomes a monumental task. This part introduces the Service Mesh pattern and advanced network security concepts, demonstrating how to shift these critical operational concerns out of your application code and down into the infrastructure layer.

### Chapters

* **[10.1. Service Mesh Architecture](/distributed-systems/en/service-mesh/service-mesh-architecture/)**: Explores the separation of the data plane and control plane, comparing industry-standard meshes like Istio and Linkerd, and how they handle traffic routing and telemetry.
* **[10.2. Network Policies and mTLS](/distributed-systems/en/service-mesh/network-policies-mtls/)**: Details "zero-trust" security inside the cluster, covering mutual TLS, pod-level firewalls, automated certificate management, and kernel-level networking with eBPF.
