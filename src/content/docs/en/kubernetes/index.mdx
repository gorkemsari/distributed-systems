Managing a handful of microservices is possible manually, but operating hundreds or thousands of them requires an automated orchestration layer. This part explores Kubernetes, the de facto standard for container orchestration, examining how it schedules workloads, maintains cluster state, and scales applications dynamically across vast pools of compute resources.

### Chapters

* **[9.1. Kubernetes: The Operating System for Distributed Systems](/distributed-systems/en/kubernetes/fundamentals/)**: Explores the core workload primitives, scheduling mechanics, autoscaling strategies, and how to extend the control plane using custom operators.
